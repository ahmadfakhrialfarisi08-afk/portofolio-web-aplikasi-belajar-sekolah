LILY_SYSTEM - Sprite Sheet Frames
=================================

6 kategori x 15 frame = 90 frame.
Semua frame disimpan sebagai PNG RGBA.

Catatan: crop dibuat berdasarkan grid sprite sheet. Jika posisi frame
pada source berbeda, sesuaikan row_y_ranges/kolom pada script.


Tambahan ekspresi (ditambahkan tanpa menghapus frame lama)
========================================================
Folder 07_EKSPRESI_PENCARIAN_PENJELASAN berisi 6 PNG RGBA baru:
01 Bingung menerima pertanyaan
02 Membaca/mencari informasi
03 Bingung mencari jawaban
04 Ide/menemukan jawaban
05 Berpikir sejenak
06 Penasaran/bertanya
